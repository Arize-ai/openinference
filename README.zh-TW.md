OpenInference 是一組與 [OpenTelemetry](https://opentelemetry.io/) 互補的慣例與外掛程式，
用於實現 AI 應用程式的追蹤。OpenInference 獲得
[Arize Phoenix](https://github.com/Arize-ai/phoenix) 與 [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference) 的原生支援，但也可以搭配任何相容於 OpenTelemetry 的後端
使用。

## 規格

OpenInference 規格以 Markdown 檔案撰寫，位於 [spec 目錄](./spec/) 中。其設計目的在於
提供對 LLM 呼叫及周邊應用程式情境的洞察，例如從向量資料庫進行檢索，
以及使用搜尋引擎或 API 等外部工具。此規格與傳輸協定及檔案格式無關，
旨在與 JSON、ProtoBuf 及 DataFrames 等其他規格搭配使用。

## 檢測

OpenInference 為多種程式語言中的熱門機器學習 SDK 與框架提供一系列
檢測套件。
