OpenInference היא אוסף של מוסכמות ותוספים המשלימים את [OpenTelemetry](https://opentelemetry.io/) כדי
לאפשר tracing של אפליקציות AI. OpenInference נתמכת באופן מובנה
על ידי [Arize Phoenix](https://github.com/Arize-ai/phoenix) ו-[Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), אך ניתן להשתמש בה גם עם כל backend התואם ל-OpenTelemetry
באותה מידה.

## מפרט

מפרט OpenInference נערך בקובצי markdown הנמצאים ב[תיקיית spec](./spec/). הוא נועד
לספק תובנות לגבי הפעלת מודלי LLM ולגבי הקשר האפליקציה הסובב אותם, כגון אחזור ממאגרים וקטוריים
ושימוש בכלים חיצוניים כגון מנועי חיפוש או APIs. המפרט אינו תלוי בפרוטוקול התעבורה או בפורמט הקובץ,
ומיועד לשימוש יחד עם מפרטים אחרים כגון JSON, ProtoBuf ו-DataFrames.

## אינסטרומנטציה

OpenInference מספקת אוסף של אינסטרומנטציות עבור SDKs ו-frameworks פופולריים ללמידת מכונה במגוון
שפות.
