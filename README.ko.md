OpenInference는 AI 애플리케이션의 트레이싱을 가능하게 하는, [OpenTelemetry](https://opentelemetry.io/)를 보완하는
컨벤션과 플러그인의 모음입니다. OpenInference는
[Arize Phoenix](https://github.com/Arize-ai/phoenix)와 [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference)에서 네이티브로 지원되지만, OpenTelemetry 호환 백엔드라면
어디에서든 사용할 수 있습니다.

## 명세

OpenInference 명세는 [spec 디렉터리](./spec/)에 있는 마크다운 파일로 작성됩니다. 이 명세는
LLM 호출과 그 주변의 애플리케이션 컨텍스트(예: 벡터 저장소에서의 검색
및 검색 엔진이나 API 같은 외부 도구의 사용)에 대한 인사이트를 제공하도록 설계되었습니다. 명세는 전송 방식과 파일 형식에 구애받지 않으며,
JSON, ProtoBuf, DataFrames 등 다른 명세와 함께 사용하도록 만들어졌습니다.

## 계측

OpenInference는 다양한 언어로 인기 있는 머신러닝 SDK 및 프레임워크를 위한
계측 모음을 제공합니다.
