OpenInference es un conjunto de convenciones y plugins complementario a [OpenTelemetry](https://opentelemetry.io/) que
permite el tracing de aplicaciones de IA. OpenInference es compatible de forma nativa
con [Arize Phoenix](https://github.com/Arize-ai/phoenix) y [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), pero también puede utilizarse con cualquier backend
compatible con OpenTelemetry.

## Especificación

La especificación de OpenInference se redacta en archivos markdown que se encuentran en el [directorio spec](./spec/). Está diseñada para
ofrecer visibilidad sobre la invocación de LLM y el contexto de la aplicación que la rodea, como la recuperación desde almacenes vectoriales
y el uso de herramientas externas como motores de búsqueda o API. La especificación es independiente del transporte y del formato de archivo,
y está pensada para utilizarse junto con otras especificaciones como JSON, ProtoBuf y DataFrames.

## Instrumentación

OpenInference proporciona un conjunto de instrumentaciones para SDK y frameworks populares de machine learning en una gran variedad de
lenguajes.
