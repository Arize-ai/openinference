Add `DOUBLEWORD` to the `LLMProvider` enum, giving Doubleword (`https://api.doubleword.ai/v1`), an OpenAI-compatible inference provider, a well-known `llm.provider` value instead of leaving it to a custom string. Mirrors the same addition in the Python, Java, and Go semantic conventions and in the spec's well-known value table.
