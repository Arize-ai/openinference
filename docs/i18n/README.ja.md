OpenInference は、AI アプリケーションのトレーシングを可能にするために [OpenTelemetry](https://opentelemetry.io/) を補完する
規約とプラグインのセットです。OpenInference は
[Arize Phoenix](https://github.com/Arize-ai/phoenix) と [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference) でネイティブにサポートされていますが、OpenTelemetry 互換の任意のバックエンドでも
使用できます。

## 仕様

OpenInference の仕様は、[spec ディレクトリ](../../spec/) にある Markdown ファイルで編集されています。この仕様は、
LLM の呼び出しや、ベクトルストアからの検索などの周辺のアプリケーションコンテキスト、
さらに検索エンジンや API などの外部ツールの利用状況を把握できるように設計されています。仕様はトランスポートやファイル形式に依存せず、
JSON、ProtoBuf、DataFrames などの他の仕様と組み合わせて使用することを想定しています。

## 計装

OpenInference は、さまざまな言語で、人気の機械学習 SDK やフレームワーク向けの計装を
提供しています。
