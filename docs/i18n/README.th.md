OpenInference คือชุดของข้อกำหนด (conventions) และปลั๊กอินที่ทำงานเสริมกับ [OpenTelemetry](https://opentelemetry.io/) เพื่อ
ให้สามารถ trace แอปพลิเคชัน AI ได้ OpenInference ได้รับการรองรับโดยตรง
จาก [Arize Phoenix](https://github.com/Arize-ai/phoenix) และ [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference) แต่ก็สามารถใช้กับ backend ใด ๆ ที่เข้ากันได้กับ OpenTelemetry
ได้เช่นกัน

## ข้อกำหนด (Specification)

ข้อกำหนดของ OpenInference ถูกเขียนเป็นไฟล์ markdown ซึ่งอยู่ใน[ไดเรกทอรี spec](../../spec/) ออกแบบมาเพื่อ
ให้ข้อมูลเชิงลึกเกี่ยวกับการเรียกใช้ LLM และบริบทของแอปพลิเคชันโดยรอบ เช่น การดึงข้อมูลจาก vector store
และการใช้เครื่องมือภายนอก เช่น search engine หรือ API ข้อกำหนดนี้ไม่ขึ้นกับรูปแบบการรับส่งข้อมูลและรูปแบบไฟล์
และตั้งใจให้ใช้ร่วมกับข้อกำหนดอื่น ๆ เช่น JSON, ProtoBuf และ DataFrames
