Ang OpenInference ay isang hanay ng mga convention at plugin na kaakibat ng [OpenTelemetry](https://opentelemetry.io/) upang
paganahin ang tracing ng mga AI application. Ang OpenInference ay likas na sinusuportahan
ng [Arize Phoenix](https://github.com/Arize-ai/phoenix) at [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), ngunit maaari rin itong gamitin sa anumang backend na compatible
sa OpenTelemetry.

## Espesipikasyon

Ang espesipikasyon ng OpenInference ay isinusulat sa mga markdown file na matatagpuan sa [spec directory](../../spec/). Ito ay idinisenyo upang
magbigay ng insight sa pag-invoke ng mga LLM at sa nakapaligid na konteksto ng application, gaya ng retrieval mula sa mga vector store
at paggamit ng mga panlabas na tool gaya ng mga search engine o API. Ang espesipikasyon ay transport- at file-format-agnostic,
at nilalayong gamitin kasabay ng iba pang espesipikasyon gaya ng JSON, ProtoBuf, at DataFrames.

## Instrumentation

Nagbibigay ang OpenInference ng hanay ng mga instrumentation para sa mga sikat na machine learning SDK at framework sa iba't ibang
wika.
