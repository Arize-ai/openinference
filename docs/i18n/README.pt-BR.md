OpenInference é um conjunto de convenções e plugins complementar ao [OpenTelemetry](https://opentelemetry.io/) para
permitir o rastreamento de aplicações de IA. O OpenInference tem suporte nativo
no [Arize Phoenix](https://github.com/Arize-ai/phoenix) e no [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), mas também pode ser usado com qualquer backend
compatível com OpenTelemetry.

## Especificação

A especificação do OpenInference é editada em arquivos markdown que ficam no [diretório spec](../../spec/). Ela foi projetada para
dar visibilidade sobre a invocação de LLMs e o contexto da aplicação ao redor, como a recuperação em vector stores
e o uso de ferramentas externas, como mecanismos de busca ou APIs. A especificação é agnóstica em relação a transporte e formato de arquivo,
e foi pensada para ser usada em conjunto com outras especificações, como JSON, ProtoBuf e DataFrames.

## Instrumentação

O OpenInference oferece um conjunto de instrumentações para SDKs e frameworks populares de machine learning em diversas
linguagens.
