OpenInference est un ensemble de conventions et de plugins complémentaires à [OpenTelemetry](https://opentelemetry.io/) qui
permet le tracing des applications d'IA. OpenInference est pris en charge nativement
par [Arize Phoenix](https://github.com/Arize-ai/phoenix) et [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), mais peut également être utilisé avec n'importe quel backend
compatible OpenTelemetry.

## Spécification

La spécification OpenInference est rédigée dans des fichiers markdown situés dans le [répertoire spec](../../spec/). Elle est conçue pour
offrir de la visibilité sur l'invocation des LLM et sur le contexte applicatif environnant, comme la récupération depuis des bases vectorielles
et l'utilisation d'outils externes tels que des moteurs de recherche ou des API. La spécification est indépendante du transport et du format de fichier,
et est destinée à être utilisée conjointement avec d'autres spécifications telles que JSON, ProtoBuf et les DataFrames.

## Instrumentation

OpenInference fournit un ensemble d'instrumentations pour les SDK et frameworks de machine learning populaires dans de nombreux
langages.
