OpenInference হলো conventions ও plugins-এর একটি সমষ্টি, যা [OpenTelemetry](https://opentelemetry.io/)-এর পরিপূরক হিসেবে
AI অ্যাপ্লিকেশনের ট্রেসিং সম্ভব করে। OpenInference নেটিভভাবে সমর্থিত
[Arize Phoenix](https://github.com/Arize-ai/phoenix) ও [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference) দ্বারা, তবে এটি যেকোনো OpenTelemetry-সামঞ্জস্যপূর্ণ backend-এর সাথেও
ব্যবহার করা যায়।

## স্পেসিফিকেশন

OpenInference স্পেসিফিকেশন markdown ফাইলে সম্পাদিত হয়, যা [spec ডিরেক্টরিতে](../../spec/) পাওয়া যায়। এটি ডিজাইন করা হয়েছে
LLM-এর invocation এবং আশপাশের অ্যাপ্লিকেশন প্রসঙ্গ, যেমন vector store থেকে retrieval,
এবং search engine বা API-এর মতো বাহ্যিক টুলের ব্যবহার সম্পর্কে অন্তর্দৃষ্টি দিতে। স্পেসিফিকেশনটি transport ও file-format নিরপেক্ষ,
এবং JSON, ProtoBuf ও DataFrames-এর মতো অন্যান্য স্পেসিফিকেশনের সাথে একত্রে ব্যবহারের উদ্দেশ্যে তৈরি।

## Instrumentation

OpenInference বিভিন্ন ভাষায় জনপ্রিয় machine learning SDK ও ফ্রেমওয়ার্কের জন্য
instrumentation-এর একটি সমষ্টি প্রদান করে।
