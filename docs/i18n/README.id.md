OpenInference adalah sekumpulan konvensi dan plugin yang melengkapi [OpenTelemetry](https://opentelemetry.io/) untuk
memungkinkan tracing pada aplikasi AI. OpenInference didukung secara native
oleh [Arize Phoenix](https://github.com/Arize-ai/phoenix) dan [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), tetapi juga dapat digunakan dengan backend apa pun yang kompatibel
dengan OpenTelemetry.

## Spesifikasi

Spesifikasi OpenInference disunting dalam file markdown yang terdapat di [direktori spec](../../spec/). Spesifikasi ini dirancang untuk
memberikan wawasan tentang pemanggilan LLM dan konteks aplikasi di sekitarnya, seperti retrieval dari vector store
serta penggunaan alat eksternal seperti mesin pencari atau API. Spesifikasi ini tidak bergantung pada protokol transport maupun format file,
dan dimaksudkan untuk digunakan bersama spesifikasi lain seperti JSON, ProtoBuf, dan DataFrames.

## Instrumentasi

OpenInference menyediakan sekumpulan instrumentasi untuk SDK dan framework machine learning populer dalam berbagai
bahasa.
