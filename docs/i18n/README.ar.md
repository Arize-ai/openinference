OpenInference هي مجموعة من الاصطلاحات والإضافات المكمّلة لـ [OpenTelemetry](https://opentelemetry.io/)
لتمكين تتبّع تطبيقات الذكاء الاصطناعي. OpenInference مدعومة أصلًا
من قِبل [Arize Phoenix](https://github.com/Arize-ai/phoenix) و[Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference)، ولكن يمكن استخدامها مع أي واجهة خلفية متوافقة مع OpenTelemetry
أيضًا.

## المواصفات

تُحرَّر مواصفات OpenInference في ملفات markdown الموجودة في [مجلد spec](../../spec/). وهي مصممة
لتوفير رؤى حول استدعاء نماذج LLM وسياق التطبيق المحيط بها، مثل الاسترجاع من مخازن المتجهات
واستخدام الأدوات الخارجية مثل محركات البحث أو واجهات API. المواصفات مستقلة عن بروتوكول النقل وصيغة الملفات،
ومُعدّة للاستخدام جنبًا إلى جنب مع مواصفات أخرى مثل JSON وProtoBuf وDataFrames.

## أدوات القياس (Instrumentation)

توفر OpenInference مجموعة من أدوات القياس لحزم SDK وأطر عمل التعلم الآلي الشائعة بمجموعة متنوعة من
اللغات.
