OpenInference este un set de convenții și pluginuri complementare cu [OpenTelemetry](https://opentelemetry.io/), care
permite tracing-ul aplicațiilor AI. OpenInference este suportat nativ
de [Arize Phoenix](https://github.com/Arize-ai/phoenix) și [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), dar poate fi folosit și cu orice backend
compatibil cu OpenTelemetry.

## Specificație

Specificația OpenInference este redactată în fișiere markdown aflate în [directorul spec](./spec/). Este concepută pentru a
oferi vizibilitate asupra invocării LLM-urilor și asupra contextului aplicației din jur, cum ar fi regăsirea din baze de date vectoriale
și utilizarea unor instrumente externe, precum motoare de căutare sau API-uri. Specificația este independentă de transport și de formatul fișierelor
și este destinată utilizării împreună cu alte specificații, precum JSON, ProtoBuf și DataFrames.

## Instrumentare

OpenInference oferă un set de instrumentări pentru SDK-uri și framework-uri populare de machine learning, într-o varietate de
limbaje.
