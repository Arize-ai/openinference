OpenInference to zestaw konwencji i wtyczek uzupełniających [OpenTelemetry](https://opentelemetry.io/), które
umożliwiają śledzenie (tracing) aplikacji AI. OpenInference jest natywnie obsługiwany
przez [Arize Phoenix](https://github.com/Arize-ai/phoenix) i [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), ale może być również używany z dowolnym backendem
zgodnym z OpenTelemetry.

## Specyfikacja

Specyfikacja OpenInference jest redagowana w plikach markdown znajdujących się w [katalogu spec](./spec/). Ma ona
zapewniać wgląd w wywołania LLM i otaczający je kontekst aplikacji, taki jak wyszukiwanie w magazynach wektorowych
czy korzystanie z zewnętrznych narzędzi, np. wyszukiwarek lub API. Specyfikacja jest niezależna od transportu i formatu plików
i jest przeznaczona do stosowania wraz z innymi specyfikacjami, takimi jak JSON, ProtoBuf i DataFrames.

## Instrumentacja

OpenInference zapewnia zestaw instrumentacji dla popularnych SDK i frameworków uczenia maszynowego w wielu
językach.
