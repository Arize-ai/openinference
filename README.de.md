OpenInference ist eine Sammlung von Konventionen und Plugins, die [OpenTelemetry](https://opentelemetry.io/) ergänzt, um
das Tracing von KI-Anwendungen zu ermöglichen. OpenInference wird nativ unterstützt
von [Arize Phoenix](https://github.com/Arize-ai/phoenix) und [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference), kann aber auch mit jedem OpenTelemetry-kompatiblen Backend
verwendet werden.

## Spezifikation

Die OpenInference-Spezifikation wird in Markdown-Dateien im [spec-Verzeichnis](./spec/) gepflegt. Sie soll
Einblick in den Aufruf von LLMs und den umgebenden Anwendungskontext geben, etwa das Retrieval aus Vektorspeichern
und die Nutzung externer Tools wie Suchmaschinen oder APIs. Die Spezifikation ist unabhängig von Transport und Dateiformat
und ist für die Verwendung zusammen mit anderen Spezifikationen wie JSON, ProtoBuf und DataFrames vorgesehen.

## Instrumentierung

OpenInference bietet eine Reihe von Instrumentierungen für gängige Machine-Learning-SDKs und -Frameworks in verschiedenen
Sprachen.
