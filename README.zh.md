OpenInference 是一套与 [OpenTelemetry](https://opentelemetry.io/) 互补的约定和插件，
用于实现 AI 应用的链路追踪。OpenInference 已获得
[Arize Phoenix](https://github.com/Arize-ai/phoenix) 和 [Arize AX](https://arize.com/products/ax?utm_source=docs&utm_medium=web&utm_content=openinference) 的原生支持，同时也可以与任何兼容 OpenTelemetry 的后端
配合使用。

## 规范

OpenInference 规范以 Markdown 文件形式编写，位于 [spec 目录](./spec/) 中。它旨在
提供对 LLM 调用及其周边应用上下文的洞察，例如从向量数据库中进行检索，
以及调用搜索引擎或 API 等外部工具。该规范与传输协议和文件格式无关，
旨在与 JSON、ProtoBuf 和 DataFrames 等其他规范结合使用。

## 插桩

OpenInference 为多种编程语言中的主流机器学习 SDK 和框架提供了一系列
插桩库。
