# OpenInference Instrumentation

Utility functions for OpenInference instrumentation: span attribute helpers,
context managers for session, user, metadata, tag, and prompt template attributes,
and tracing configuration.

```shell
pip install openinference-instrumentation
```

For usage guides, see the
[package README](https://github.com/Arize-ai/openinference/tree/main/python/openinference-instrumentation#readme).
